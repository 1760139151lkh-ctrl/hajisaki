# 哈基祥 · 界面设计语言：公主的小客厅

手机端（`studio/`，即 Android APK 与电脑控制台共用的界面）和 iPad（`ipad/App/Sources/Views/TheaterTheme.swift`）用的是同一套设计语言。鸿蒙工程的 `phone/harmony/entry/src/main/ets/design/Theme.ets` 只同步了色值。离线富文本的色值在 `studio/src/frame.css`；改动任何一端的色值，都要同步更新其余几处，并重建 iPad 的 `Renderer/renderer.css`。

## 气质

像一位大小姐的私人小客厅：瓷白与珍珠、玫瑰与古金，有祥子的藏青缎带、小小的冠冕、火漆封印的爱心，还有金色花饰。华丽，但始终克制：

- 版式沿用“信笺”结构，留白充足，用细线分隔，不加厚重阴影。
- 装饰只用细金线和少量小图形，不用虚线描边、糖果渐变或贴纸。
- 玫瑰色承担主要操作和心意时刻；她的发色长春花蓝只留给链接。
- 祥子的声音用衬线体；短句拉丁文签名用花体；你的内容用无衬线体。

## 字体

- **衬线**：Noto Serif SC Medium 子集（Haji Serif，iOS 字体名 `NotoSerifSC-Medium`），覆盖 GB2312 一级字与界面里出现的全部字符。
- **花体**：Pinyon Script（Haji Script，iOS 字体名 `PinyonScript-Regular`），只用于金色的短句拉丁文：
  - 首页问候 *Good morning / Good afternoon / Good evening / Sweet dreams*
  - 小纸条落款 *— Sakiko*
  - 页面小标题 *Little things about you*、*Treasures*、*Just for you*
  - 空对话上方的 *Only for you*
  - 静谧阅读的落款 *Sakiko*

  不要用它写中文。
- 两种字体都按 SIL OFL 1.1 随包分发，授权文本放在字体旁边。界面文字有改动后，重新运行 `assets_pipeline/subset_ui_font.py`。

## 母题

- **拱窗肖像**：首页把窗边的祥子放进半圆拱顶的珍珠画框（7pt 衬边加一道金线）。她的藏青缎带蝴蝶结停在拱顶上，金色虚线缝迹取自原画发带，轻轻左右摇摆（±2°，7 秒一个来回；开启“减弱动态效果”后静止）。
- **冠冕**：一顶小小的金冠，戴在 `祥` 字火漆印上（品牌），也跟在消息里她的名字后面。
- **火漆心**：寄出键和“写信给祥子”入口都是一枚压着象牙色爱心的玫瑰火漆；没写内容时，寄出键退成素色圆。
- **字母圆章**：信笺列表里，每封信前有一枚珍珠圆章，用衬线写出标题的第一个字（跳过标点）；置顶的信在右上角别一颗小心。
- **金框卡片**：她的小纸条、记忆、设置里的在线状态卡，都是外镶一道金线、内侧再一道浅金线；小纸条底边是蕾丝花边。
- **花饰分隔**：金色卷草细线，中间一颗玫瑰色小心。用在小纸条、信笺标题、对话框标题和空状态上方。

## 交互细节

- 手机用底部导航；进入聊天后收起导航，只留下你和她的对话。Android 返回键先关闭弹出的面板，再回到琴房首页。
- 新乐章的空白页提供几句起笔；点了只放进草稿，不会自动寄出。
- 头像会随状态换表情：写回信时托腮，回完开心一下，断线时担心，深夜捧茶，凌晨犯困。
- 只有新出现的内容才播放入场动画（Android 端每 850ms 轮询一次，不能让整页反复闪动）；所有动效都遵循系统的“减弱动态效果”。

## 她的话

问候、小纸条、回信路上的短句和设置里的试读句，都写在同一处：手机端 `studio/src/voice.ts`，iPad 端 `TheaterTheme.swift` 的 `CompanionMood`，两边措辞与时段一致。

- **时段**：23–3 点深夜、3–5 点破晓前、5–11 点早晨、11–14 点中午、14–18 点午后、其余为傍晚和夜里。花体问候、标题寒暄和日期里的时段都取自同一个钟点，不会出现 “Good morning” 配 “午安”。
- **温度跟着调律走**：“端庄与温柔”拉向卸下防备（formality ≤ 40）时多一些甜；“傲娇的程度”拉高（teasing ≥ 60）时换成嘴硬心软的说法，两者都高就都会出现。
- **称呼**：设置里的“她怎么称呼你”会存到主机，提示词里写明这是对方希望的亲昵称呼；界面上只在问候第一句和几句甜的小纸条里出现，长于六个字时不放进标题。
- **特别的日子**：元旦、2 月 14 日（她的生日，也是情人节）、5 月 20 日、平安夜、圣诞、除夕，问候和小纸条换成当天的话；深夜仍以“去睡吧”为先。
- **试读**：设置里拖动滑杆或改称呼时，“She’d say” 下面立刻换成她此刻会怎么回“今天把报告写完了”，保存之前就能听到。
- **新信的名字**：新乐章寄出第一封信后，主机用第一行（跳过引用和 Markdown 记号，最多 18 个字）为它命名，打开着的信头会轻轻换上新名字。

## 她在

不是只在回信时才出现：

- **相识第 N 天**：从这台主机上的第一封信算起（第一天算第 1 天），写在首页日期旁、iPad 侧栏日期下面。第 7、30、100、200、365、520、1000 天和每个整年，小纸条换成那一天的话。
- **好久不见**：这次打开时，离上一封信已经三天以上，首页问候换成 *Welcome back*：“好久不见。”或傲娇的“三天没来信。……我才没有在数日子。”，一次打开只算一次。
- **轻轻叫她一声**：点首页拱窗、聊天页头像或 iPad 顶栏的小像，她会用此刻的口吻回一句，像珍珠小气泡一样浮出再退下，头像跟着换表情；连点五次，她会害羞或嘴硬地“投降”。离开页面后重新计数。
- **在等你写完**：你在信纸上写字时，信头那行字变成“在等你写完…”（傲娇时是“写这么久……是在写情书吗？”），停笔四秒或离开输入框后恢复。
- **深夜的一次**：过了十一点、打开超过 25 分钟后，聊天页顶部会出现一张 *Sweet dreams* 的小卡片劝你去睡，每晚只出现一次；“好，这就去睡”换来一句晚安，“再聊一会儿”她也会答应，只是嘴上要管着时间。
- **她的贴纸**：三张Q版贴纸各有固定的时刻——深夜卡片上举着“快去睡觉！”，帮你查资料时举着“交给我吧”，你勾掉她列的一项时弹出“勉强夸你一句”。原图在 `shared/assets/stickers-youth`（iPad 资源目录直接使用），手机用 `assets_pipeline/web_art.py` 生成的 360px WebP（`shared/assets/stickers-web`，每张约 45 KB）。
- **场景插画**：琴房断开连接时，拱窗换成雨夜里空着的琴房，玻璃外有雨丝落下，写着“灯熄着，雨一直下。等你把琴房接回来。”；接回来时窗里重新是她，并冒出一句“……灯亮了。欢迎回来。”。搜索不到时，是雨里站在路灯下的她：“我在路灯下找了一圈……还没找到「…」。”记忆页用藏青烫金的玫瑰手账作封面，并写“关于你的事，我已经记下 N 件了。”手机用 `shared/assets/scenes-web` 里的 WebP，iPad 用资源目录里的原图。
- **琴音**：打开“琴音”时先响一声，让你知道会听到什么；钉住一段话、收进一件记忆时也会轻轻响一下（只在开着琴音时）。
- **活的窗，随季节变**：首页拱窗里，白天春天飘樱花、夏天有光点慢慢浮起、秋天落几片琥珀色的叶子（与窗外画里的秋树一致）、冬天下雪；夜里有几颗星星明灭，冬夜里还会落雪。开启“减弱动态效果”时不显示。
- **iPad 的窗**：右侧“琴房”画面同样随季节飘落花瓣、光点、落叶或雪，夜里有星星；琴房断开时换成雨夜空琴房，下方文字也跟着变；点一下画面，她会回应。侧栏的花体问候同样一笔写出来。
- **她亲手写的字**：每次回到首页，花体问候像笔尖写过一样从左往右显出来，小纸条的落款 *— Sakiko* 随后再写上；减弱动态效果时直接显示。

- **每一次操作都有回应**：置顶、取消置顶、归档、取回、改名、换册、从某处另起一页、请她先停、换思考深度、导出、配对成功、文件收进信里，她都会用一句话回应（手机是提示条或头像旁的气泡，iPad 是对话区底部的珍珠胶囊）。“收起这把钥匙”会先问一句，确认后才断开。约定也一样：记下时说“约好了。11月18日 23:00，我会叫你。”，暂停、继续、收到她的话时各有一句；删掉一件记忆、在首页切换昼夜、点设置页里的小像，她都会回应。珍藏页标题下写“这里替你收着 N 件珍藏。”

## 中间状态

每一个等待都要说清楚“她在做什么”，而且用她的口吻。

- **寄出**：你的信先以半透明出现，旁边是一枚轻轻晃动的信封“寄出中”；断线时写“等琴房亮灯就寄出”，主机没接住时才变成“没能寄出 · 再寄一次”。
- **回信在路上**：还没写下第一个字时，不放空白的信，只在末尾留一行小字和三颗跳动的心：“在读你的信” → 查资料时“在帮你查，马上就好” → 超过 30 秒“想得有点久，再等我一下”。信头的状态同步显示“在读你的信… / 在查资料… / 正在写回信…”。
- **新的一页**：刚翻开、还没写字的信，标题跟着时辰换：早上“早上的第一封信，是写给我的吗？”，傍晚以后“今天发生了什么，都告诉我吧。”，深夜“夜里的话，我都听。”，其余时候“这一刻，只听你说。”。
- **再要一张小纸条**：点一下她的小纸条（iPad 是没有打开信时舞台上那句），会翻出另一句；第三次她会说“……今天的份就这些了。明天再来。”（傲娇时“……贪心。今天就这些，明天再给你写。”）。
- **搜索高亮**：搜索信笺时，标题和预览里命中的字用玫瑰色淡淡标出；搜索框的清除键也换成了细细的玫瑰色叉，不再是浏览器自带的蓝色。
- **今天想弹给你听**：小纸条下面一行小字，写着她今天想为你弹的钢琴曲和一句话，比如“李斯特《爱之梦》第三首 —— ……曲名你别多想。”；每天一首，晚上九点以后换成《月光》《梦幻曲》《夜曲》这样安静的曲子。iPad 在没有打开信时的舞台上显示。
- **周日的手账**：每逢周日，首页小纸条下面（iPad 是没有打开信时的舞台上）多一页手账：“这一周，你写来 N 封信，心动了 M 次。……下周也请多指教。”，配那本藏青手账的封面；这一周什么都没有时不出现。
- **回到一封信时**：打开一封有新回信、你还没看过的信，她说“回信写好了，慢慢看。”（傲娇时“……终于来看了？”）；打开一封你写到一半的信，她说“你上次写到一半的，我替你留着。”。已经看过、也没有草稿的信不打扰。
- **心动**：她的每封回信下都有一颗心（iPad 在消息菜单里）。点亮后她名字旁留一颗小心，她会回一句（“嗯。……我看到了。”，傲娇时“……这种话也值得心动吗。（小声）谢谢。”）。手机上先选中她的某一句再点心，收下的就是那一句；没选就收这封信的开头。手机的记忆页和 iPad 的记忆星空都会把这些句子收成“你心动过的话”，点一句就回到那封信。心动只记在这台设备上。
- **她看得见你寄来了什么**：读信那一行会跟着你的信变：附了图片是“在看你发来的画面”，有录音是“在听你录的声音”，有文件是“在读你给的资料”，超过三百字是“这么长的信，我会认真读完”，凌晨一点到五点寄出的是“这么晚的信，我在读了”（傲娇时“……都这个点了还写信。读完就去睡。”），同样随她的温度变化。回信超过九百字时，写完她会补一句“写得有点长，慢慢看。”（傲娇时是“……写得有点长。不许跳着看。”）。静谧阅读里的落款 *Sakiko* 也会一笔写出来。
- **已读**：你最新的那封信下面，等她真的开始读（不是刚排上队）时，出现一个玫瑰色的“♥ 已读”；再寄一封，它就挪到新的那封下面。不加入场动画，因为她写字时列表会不断重绘。
- **她的小纸条**：工作途中她递来的短句（narration）用衬线体，前面一支金色羽毛笔，靠左，像夹在信里的便笺。
- **工作札记**：一次回信里的工具步骤合成一枚胶囊，同一调用只显示一次、取最新状态；正在做的那一步用会动的羽毛笔，出错或待授权的一步用玫瑰色。点开后列出全部步骤，展开状态在她继续写时保持不变。
- **落笔**：正在写的那一行末尾有一颗跳动的小心，像笔尖还停在纸上；写到代码块或表格时，小心落在块的下面。消息列表在流式写入时会反复重绘，所以循环动画用同一个 `--clock` 相位，不会每帧从头开始。
- **封缄**：回信写完，她名字后的冠冕升起两颗小心，头像外圈泛一次玫瑰色光；如果你正往上翻着看，底部按钮会写“她回信了”，她还在写时写“她还在写”。
- **写失败的信**：一个字都没写成时，只留一句“这封回信没能写成”和“放回信纸，再寄一次”，把你上一封信放回草稿；空信不显示复制、钉住等按钮。
- **信笺列表**：她正在回信的那一封，圆章套一圈玫瑰色，预览换成“正在给你写回信…”；写完而你还没看过的，在时间旁边点一颗玫瑰色的小圆点，标题加粗。列表在她写信期间每 2.5 秒（iPad 3 秒）看一次；在首页时写完会提示“「标题」有回信了。”。“看过”只记在这台设备上。
- **加载**：第一次取回信笺、记忆、珍藏时用金线色的微光占位，打开信时写“正在展开信纸…”，不再先闪出“还空着”的页面。
- **提示条**：宽度跟着文字走，最多到屏幕宽减 40px，多行时是 20px 圆角的卡片，而不是被挤成一团的胶囊。
- **收下的瞬间**：记下一件事、钉住一段话时，她会回一句（“嗯，我记住了。”“钉好了。这一段，我会一直放在手边。”）。手机上是带小心的提示条，新记下的记忆在列表里泛一次玫瑰色光；iPad 上是对话区底部升起又退下的珍珠胶囊。

## iPad

iPad：令牌与组件集中在 ipad/App/Sources/Views/TheaterTheme.swift（TheaterPalette、WaxSeal/WaxHeart、SakiSeal、TiaraMark、RibbonBow、MonogramRoundel、ArchedPortrait、FiligreeDivider、ScriptLine、letterCard）。字体随包放在 App/Resources/Renderer/fonts，并在启动时由 TheaterFonts.register() 注册；Renderer 是文件夹引用，所以不需要改工程。侧栏对应手机首页：花体问候、衬线寒暄、日期与在线点、封蜡心形写信入口、带字母圆章的信笺列表。iPad 的全局 tint（滑杆、开关、进度）、文字操作（“完成”“重新写”“引用到草稿”“复制”等）和选中态都用玫瑰色，与手机端 `.text-button` 一致；长春花蓝只留给消息里的链接和 Pencil 悬停光晕。
