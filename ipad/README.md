# 哈基祥 · iPad 剧场

独立 iPadOS 原生客户端，SwiftUI + UIKit + PencilKit + PDFKit。与手机共享 Windows 网关、消息协议、原件与人物身份；三栏阅读与手写工作台独立设计。

当前核心交付版本为 **0.1.0（7）**。界面设计语言“公主的小客厅”与手机端共用（拱窗肖像、缎带与冠冕、火漆爱心、字母圆章、头像随心情变化），色值集中在 `App/Sources/Views/TheaterTheme.swift`，说明见 `../docs/ui-design-language.md`。按用户最新要求，以真实聊天、文档/手写、数据恢复和可签名安装包收尾；使用与验收边界见 `../docs/ipad/core-delivery.md`。原始120项保留在长期台账，不把模拟器观察当成真机性能结论。

## 构建

仓库根目录运行 `python ipad/tools/prepare_project.py` 同步选用资源并生成可直接打开的 `App/HajiSaki.xcodeproj`。源工程已带入生成的资源和离线富文本包，在 Mac 上可独立使用 Xcode 打开并构建，不需要 Codex、云端构建或 XcodeGen。

```sh
cd ipad
bash tools/build.sh
```

目标为 iPadOS 18 及以上，bundle ID `app.hajisaki.theater.ipad`。模拟器构建不需要 Apple 账号；安装到实际 iPad 需要正常签名。构建产物、模拟器观察与真机性能分别记录。

修改共享富文本源后，在仓库根目录构建平板内置包，再同步工程：

```powershell
python tools/run.py --cwd studio -- node node_modules/vite/bin/vite.js build --config ../ipad/renderer/vite.config.mjs
python ipad/tools/prepare_project.py
```

`studio/src/render.ts` 是现有跨端富文本能力的构建源，平板只复用其排版算法，没有复用手机布局。目录迁移以 `docs/directory-coordination.md` 为准；构建后的 Renderer 在 App 内离线运行，禁止外部网络、远程脚本与网页框架。

## 使用

在“连接电脑”填入自己的琴房 HTTPS/加密私网地址、配对设备标识和口令。口令只保存至本机 Keychain，不能填入网址。模型与思考档位读取主机实际目录。本地演练服务会明确标注“非 AI”。

聊天名录、消息、事件游标、草稿及待寄出消息保存在 App 的 SQLite 中。每个主机与设备标识拥有独立本地库；断网时可翻阅已缓存内容，编辑草稿与既有对话的待发送队列。主机返回正式快照后才确认投递，重试沿用原消息 ID。

横屏使用名录—对话—侧幕/共创台；窄窗把辅助区域收进独立面板。草稿纸保留可编辑笔迹，PDF/图片可进入批注页，把圈画后的图片附到对话。没有图形设备的虚拟环境使用受限的软件绘图路径，不能据此判定 Apple Pencil Pro 的真实延迟、压感或触感。

顶栏怀表或⌘⇧P可打开五动作环：圈选追问、高光标记、展开草稿、语音附耳与思考档位。圈画完成后保存原始底图、可编辑笔迹和截图，递交按钮把截图附到当前草稿，不自动发送。“更多→圈画手稿”可重开当前乐章的圈画，继续编辑并保留原件。旋转或翻页后原截图仍可递交，旧坐标笔迹会隐藏；Pencil系统手势偏好保留。真实Pencil Pro的悬停、捏合、旋转和触感仍需实机验收。

点击消息中的蓝色文件名，可在卷宗打开原件并定位到实际页或代码行；固定上下文中也可展开摘记并打开原件。PDF的页码和柔光状态会在横竖屏切换时保留。正文使用原生文字与离线公式等复杂块混合排版；往上读时不会因新回复强拉到底部，可点“回到最新”继续看回复。

Markdown文件在卷宗以离线阅读模式打开，可查看公式和横滑表格，并切换源码。当前文件的阅读位置、表格横滑和源码模式随布局切换保留；换文件或重开应用后重新开始。预览限2MiB以内UTF-8文件，超过范围仍可分页看原文并导出原件。同一乐章重连保留已显示的正文、草稿和附件，不先清空再载入。

消息语义块由原生UITableView统一复用，避免长回复和发送后出现整栏空白。含公式的待办正文使用同一离线数学渲染器，勾选状态独立保存并同步到主机。“选择整条文字”提供原生连续选择页；独立TextKit/WebKit表面之间的任意跨块拖选仍在全范围台账中。

侧幕新增昼夜各4种完整坐姿：输入时看笔记、模型运行时托腮、工作台顶栏近景看向页面，以及手动“陪我喝杯茶”。眨眼只使用对应眼区，茶雾是独立动态层；系统减弱动态会停动。当前不是12种完整全身情绪，也没有把眨眼/茶雾称作完整Metal呼吸、发梢与雨丝引擎。

模型交付或从“文件”选择的HTML/HTM，可直接在卷宗里打开为交互微剧场，调节滑杆、观察曲线，也可切到源码。支持2MiB以内的UTF-8离线单文件；当前卷宗在源码和预览、横竖屏之间切换时保留演示参数。换一份卷宗或重开应用会重新开始。演示页不连接外部网络或取得设备/原生文件权限，原件可照常导出。

PDF或图片的“批注”保留独立可编辑笔迹；“递给祥子看这段”把合成PNG放回草稿，不自动发送。笔迹按资料库、原件内容摘要和页码识别，避免应用更新改变沙盒路径后找不到笔迹。同一资料库里，同一原件从文件柜打开或从“文件”App重新导入时可共用笔迹。

卷宗的“导出”使用原生文件保存器，按原文件名保存副本。导出目录可在“本机→哈基祥”访问；数据库、配对口令及内部缓存位于私有存储。选择外部原件时使用安全作用域和协调读取，再保留本机副本。当前位置的文件选择/保存已在模拟器走通；从Mac拖PDF到Simulator被系统Preview接管的路径没有算作哈基祥跨App拖拽通过。

## 设备构建与接入条件

当前安装输入为 `outputs/install-build7/HajiSaki-iPad-0.1.0-build7-03ba2d3c-unsigned.ipa`（88,020,621字节，约83.94MiB），安装说明在同目录README。设备包为未签名的arm64 IPA，需用正常Apple签名后安装；模拟器的ad-hoc签名不替代真实iPad签名。免费个人账号的设备描述文件通常7天到期，须重新签名安装，见[Apple Personal Team说明](https://developer.apple.com/help/account/basics/about-your-developer-account)。Apple账号、OTP、设备信任和开发者模式由本人在设备或安装器完成，口令不要写进工程或聊天。原build2至build6包保留；本版设备回执在`outputs/device-build7-final/`。

真实模型已复用Windows主机现有Antigravity登录完成文字、PDF首页摘录和批注图像回复。当前模拟器的`127.0.0.1:18767`是开发SSH转发；真实iPad不能用它连接主机。实机还需自己的私有通道地址和独立设备配对，广域网双通道部署及切网指标仍未验收。需要麦克风时由用户主动点击录音再请求权限，应用不需要位置权限。
