# 手机原生工程

源码现位于 `phone/harmony/`，与平板任务的 `ipad/` 分开。共享网关、控制台、富文本构建源、语音、加密中继和原始资源保留在项目外层。

当前分支经用户确认继续原提示词的鸿蒙手机工程，目标为 HUAWEI Pura 80 Pro、HarmonyOS 7 / API 26，交付 HAP。原对话继续 iOS；手机要求没有改成另建 Android APK。

原生输入区已接入 `@` 电脑代码、文件夹和历史消息选择页；主机浏览器可配置开放目录。选择产生带来源和摘要的引用附件，点击“送出”后才进入模型上下文，真实模型已读取三类引用并正确回答。实际检查包括 320vp、日夜配色、历史翻页、草稿保留、超限与断线重试；实时消息刷新缺陷已修复并用真实后续回复复查。合同和仍未验收的设备边界见 [native-references.md](native-references.md)。

`/` 的常用起笔与当前乐章语气已接入并有原生操作及真实接口观察；原生长上下文整理后的真实续聊已确认74882→25976 tokens、事实保留、原始记录不变及同一模型会话。[native-composer.md](native-composer.md)记录确认时差、失败历史和仍待设备验收的边界。

原生“随手画室／照片批注”已接入首页、聊天附件与档案，包含画笔、编号、马赛克、四角透视、旋转、纸张增强、操作恢复和 PNG 附件交接；前后端合同及实测边界见[native-image-studio.md](native-image-studio.md)。

聊天内图片、图片墙、大图缩放/柔光/追问及工具实际读图的画面凭证已接入。真实 ACP 工具返回图片或指定 PDF 页的像素，原生页面可打开对应画面；缩略图与已访问页面缓存和加密中继路径已有实际观察。合同及剩余边界见[native-images.md](native-images.md)。

手机已增加本地 ThumbHash 解码，轻量元数据先于图片传送，原生占位到清晰图片的中间过程已有原始帧记录；修复了占位与原图留边不一致的问题。真实 GIF 首帧、模型读取及断连缓存重开也已观察，具体证据见同一图片文档。

原生备用通道的设备绑定导出、导入、安全存储合同与当前实测边界见[native-relay-import.md](native-relay-import.md)。其实现与预览观察不代替设备TLS、安全存储恢复或外网双模验收。

当前实际构建和预览分为三个口径：

- Huawei HarmonyOS 26 默认产品：需要对应华为 SDK、签名与设备权限。
- OpenHarmony API 26 产品：已进行真实编译；公共平台兼容性证据，不冒充华为设备特权验证。
- 临时存储预览产品：只为可操作的本地预览提供会话内存储，继续使用真实网关；不会证明加密 SQLite、重启持久化或真机性能。

工具链与实测记录见外层 `docs/platform-environment.md`、`docs/acceptance-ledger.md`；原始要求未因目录迁移减少。原生主项目与暂存构建的身份、数据目录及已存在会话保持不变。

当前主机使用真实Antigravity ACP通道，已有本机登录可用。根代理通过原生表单完成配对，从档案选择公开音频后实际转写，并将结果放回未发送草稿；未录制用户麦克风。手稿与音频分别保留，未绑定原音的便笺可在“从档案选择 → 随手便笺”找回。

ACP已接通会话附件读取、受管文字与PDF/XLSX/ZIP成品工具。原生“翻阅”能显示文字原文、主机解析的PDF纸页、真实工作表与归档目录；切表/行分页/固定表头首列、PDF放大平移和已缓存页重开已有实际观察，仍在补齐恢复与导出验证。具体边界见`native-document-readers.md`。原生ArkWeb仍受桌面预览器限制，不能将浏览器卡片交互当作手机Web组件验收。

仍需本人或设备参与的条件：华为开发账号取得对应SDK与设备签名、手机调试信任，以及使用麦克风/相机/文件/通知/生物识别时的真实系统权限。应用始终不申请定位。外网通道还需要实际可达的部署端点和设备证书；原生Mesh与系统实况窗等也仍有实现工作，不能把它们仅称为“缺登录”。这些条件不阻止继续开发共享网关、原生页面与可独立验证的业务链路。

实际HAP、源码摘要和构建记录位于外层 `releases/`。本机可重复构建命令见 `phone/harmony/README.md`；当前工具链的SDK参数使用已有ASCII别名 `C:/Users/17601/hajisaki-workspace/tooling/openharmony-sdk`，不改写SDK身份清单。


模型选择已按家族与思考强度分开，面板限高、日夜及320vp均已实际复查，见[model-picker.md](model-picker.md)。真实选文附页及仍待验收的对照范围见[native-branches.md](native-branches.md)。
