# HajiSaki 视觉工坊

客户端资源入口是 `native-resources.json`；它只选择少女版祥子与配套图标、场景和贴纸。`asset-manifest.json` 记录实际尺寸、字节数、SHA-256、原始提示词和来源。

人物母版来自用户“在场”项目，直接复制为 `shared/assets/avatars-youth/idle_gentle.png`。日夜琴房陪伴图也直接复制原图。原始来源及复制后的哈希见 `user-reference-manifest.json`。人物以原图的琥珀眼、银蓝长发、柔和少女脸型、校服开衫和简单蝴蝶结为准，优先于初稿中的灰蓝眼与成熟哥特服饰。

缺少的九态表情、五枚拟物图标、四张主题插画和三张贴纸使用内置 `image_gen` 生成。少女版四视角 Character Sheet 位于 `shared/assets/reference-youth/character-sheet.png`，由用户头像和校服场景共同约束；用户原头像仍是身份基准。每个输出单独保存并查看；人物变体始终引用少女版母版。未调用付费 API，也未用程序重绘、缩放或修改原图。

在项目目录执行以下正常构建入口可刷新资产清单；仅需 Python 标准库，不依赖 Codex 内部文件或服务：

```text
python assets_pipeline/build_manifest.py
```

提示词与生成来源按人物、图标、场景分开保留；完整可用文件都在项目内，来源路径只是制作记录。旧哥特头像和早期贴纸保留在历史清单中，不被最终资源入口选中。

十态头像与三张最终贴纸实际为 1254×1254；图标为 1254×1254；开屏图为 752×2092。原生设备 @3x/@4x、200% 零白边、真实主题合成、小尺寸可读性、动态切换与性能仍需在集成页面和手机上确认。透明通道存在不等于这些指标通过。
